# Baixa Resolução

Orientações para desenvolvimento do projeto Baixa Resolução (editorial de tecnologia da origemdev).

- Frontend construído com React 19, Vite, TanStack Router e TanStack Start.
- Estilização com Tailwind CSS v4 e Shadcn UI.
- Mock de dados estático em `src/data/articles.ts`.
- Mantenha a identidade visual editorial/analógica com toques digitais.
