# BAIXA RESOLUÇÃO

**por origemdev**

> Alta tecnologia. Baixa resolução.

---

## 1. Conceito

**Baixa Resolução** é o editorial de tecnologia da **origemdev**.

A publicação deve abordar tecnologia não apenas como produto ou ferramenta, mas como um fenômeno que atravessa cultura, comportamento, sociedade, design, trabalho e futuro.

A identidade visual parte de uma contradição:

> **Uma estética analógica para falar sobre um mundo digital.**

A referência visual combina:

- estética editorial impressa;
- revistas independentes;
- jornais e publicações dos anos 70/80;
- papel envelhecido;
- tipografia serifada expressiva;
- blocos de cor;
- elementos gráficos desenhados à mão;
- composição modular;
- elementos de interface e linguagem digital.

O resultado deve parecer uma **revista independente sobre tecnologia**, e não um blog corporativo ou um portal tradicional de notícias.

---

# 2. Direção estética

## Conceito visual

### PAPEL + PIXEL

A linguagem visual deve combinar dois universos:

**Analógico**

- papel;
- impressão;
- editorial;
- jornal;
- revista;
- textura;
- imperfeição;
- desenho manual;
- composição gráfica.

**Digital**

- pixels;
- interfaces;
- grids;
- códigos;
- dados;
- ruído digital;
- dithering;
- scanlines;
- baixa resolução;
- elementos técnicos.

A tecnologia deve aparecer como uma camada sobre uma estética essencialmente editorial.

---

# 3. Princípio visual

A publicação não deve parecer "cyberpunk".

Evitar:

- excesso de neon;
- fundos pretos com azul elétrico;
- estética gamer;
- excesso de glitch;
- interfaces futuristas genéricas;
- excesso de gradientes;
- visual de SaaS;
- cards excessivamente arredondados.

A ideia é criar uma estética **editorial, intelectual e contemporânea**, utilizando elementos tecnológicos de maneira pontual.

# 5. Tipografia

O sistema tipográfico deve utilizar três famílias principais.

---

## 5.1 Display — Instrument Serif

**Fonte principal para títulos editoriais.**

Uso:

- manchetes;
- títulos de matérias;
- grandes chamadas;
- títulos de seções;
- frases de impacto.

Características:

- editorial;
- sofisticada;
- expressiva;
- contemporânea;
- forte presença visual.

Exemplo:

> A INTERNET  
> ESTÁ  
> QUEBRADA?

Os títulos devem funcionar quase como elementos gráficos.

### Tamanho sugerido

Desktop:

`72px – 120px`

Line-height:

`0.85 – 1.0`

Mobile:

`48px – 72px`

---

## 5.2 Body — Inter

Fonte principal para leitura.

Uso:

- corpo dos textos;
- subtítulos;
- navegação;
- descrições;
- chamadas;
- textos auxiliares.

Características:

- neutra;
- legível;
- contemporânea;
- excelente para interfaces;
- cria contraste com a serif.

### Tamanho sugerido

Body:

`16px – 19px`

Line-height:

`1.45 – 1.6`

---

## 5.3 Technical — IBM Plex Mono

Fonte monoespaçada para elementos tecnológicos e metadados.

Uso:

- categorias;
- datas;
- horários;
- autores;
- números;
- tags;
- informações técnicas;
- códigos;
- pequenos labels;
- indicadores;
- elementos de interface.

Exemplo:

````text
BAIXA RESOLUÇÃO / 07.09.2026
TECNOLOGIA / IA
LEITURA — 06 MIN

Tamanho sugerido

11px – 14px

Preferencialmente em uppercase.

6. Tipografia experimental

Uma fonte pixel/bitmap pode ser utilizada como recurso complementar.

Possíveis opções:

Pixel Operator

VT323

Departure Mono

Ela não deve ser utilizada para textos corridos.

Uso exclusivamente como detalhe visual:

LOADING...
SYSTEM 04
SIGNAL LOST
ERROR 404
198.42 MB

A função é reforçar o conceito de "baixa resolução", sem transformar o editorial em uma estética gamer.

8. Grid

O editorial deve utilizar uma estrutura modular inspirada em revistas e publicações impressas.

Desktop

Grid de:

12 colunas

Características:

margens generosas;

gutters pequenos ou médios;

composição assimétrica;

módulos de diferentes tamanhos;

blocos de texto e imagem;

divisórias horizontais e verticais.

A composição não deve parecer um dashboard.

Deve parecer uma página editorial.

Exemplo conceitual:

┌────────────────┬──────────────────────────────┐
│                │                              │
│   CATEGORIA    │                              │
│                │         HEADLINE             │
│                │                              │
├────────────────┴────────────────┬─────────────┤
│                                 │             │
│       MATÉRIA PRINCIPAL         │   DESTAQUE  │
│                                 │             │
└─────────────────────────────────┴─────────────┘

9. Formas

A interface deve evitar excesso de elementos arredondados.

Preferência por:

quadrados;

retângulos;

linhas;

divisórias;

círculos pontuais;

formas geométricas;

elementos irregulares desenhados à mão.

Border radius

Preferencialmente:

0px

ou valores extremamente pequenos quando necessário.

A ausência de arredondamento ajuda a preservar o caráter editorial e impresso.

11. Texturas

A identidade pode utilizar texturas de maneira controlada.

Analógicas

papel;

granulação;

impressão;

tinta;

halftone;

pequenas imperfeições.

Digitais

dithering;

ruído;

pixels ampliados;

scanlines;

artefatos de compressão;

baixa resolução.

A textura deve ser uma camada sutil.

Não deve prejudicar a legibilidade.

12. Imagens

As imagens devem participar da linguagem editorial.

Evitar imagens excessivamente genéricas de bancos de imagens.

Priorizar:

fotografia documental;

fotografia tecnológica;

imagens de arquivo;

screenshots;

fotografias de objetos;

imagens de laboratório;

imagens de infraestrutura;

retratos;

imagens com composição gráfica forte.

Tratamento de imagem

Algumas imagens podem receber:

dithering;

redução proposital de resolução;

halftone;

granulação;

duotone;

recortes geométricos;

sobreposição de elementos gráficos.

O efeito deve ser utilizado como recurso editorial, não como filtro obrigatório.

13. Dithering

O dithering pode ser uma das assinaturas visuais da Baixa Resolução.

Imagens importantes podem ocasionalmente ser convertidas para uma estética semelhante à impressão de jornais antigos.

Exemplo conceitual:

FOTOGRAFIA
     ↓
REDUÇÃO DE RESOLUÇÃO
     ↓
HALFTONE / DITHERING
     ↓
IMAGEM EDITORIAL

Isso conecta diretamente o nome Baixa Resolução à identidade visual.

14. Layout

A página deve trabalhar com grandes contrastes entre:

imagem e texto;

espaços vazios e blocos densos;

serif e monospace;

papel e preto;

analógico e digital;

escala grande e pequenos detalhes.

A composição deve ter personalidade.

Evitar:

grids excessivamente uniformes;

repetição automática de cards;

layouts de blog tradicionais;

excesso de componentes iguais.

15. Editorias

O editorial terá quatro grandes categorias:

TECNOLOGIA

Acompanhamento dos acontecimentos tecnológicos.

Conteúdos:

lançamentos;

novas tecnologias;

inteligência artificial;

startups;

big techs;

software;

hardware;

internet;

aquisições;

produtos;

acontecimentos relevantes da indústria.

É o núcleo mais noticioso da publicação.

CULTURA

A relação entre tecnologia, sociedade e comportamento.

Conteúdos:

cultura de internet;

redes sociais;

comportamento digital;

memes;

comunidades online;

trabalho;

relacionamentos;

privacidade;

estética digital;

gerações;

hábitos;

impacto social da tecnologia.

Exemplos:

Por que todo aplicativo agora parece uma rede social?

A internet está ficando silenciosa?

FUTURO

Tecnologias e possibilidades que apontam para o que vem pela frente.

Conteúdos:

inteligência artificial;

robótica;

computação quântica;

realidade aumentada;

realidade virtual;

interfaces cérebro-computador;

automação;

cidades inteligentes;

novas formas de trabalho;

biotecnologia;

exploração espacial;

tecnologias emergentes.

Pode combinar notícia, análise e projeção.

OPINIÃO

O espaço mais autoral da publicação.

Conteúdos:

análises;

ensaios;

críticas;

investigações;

contradições da indústria;

ética;

monopólios;

algoritmos;

vigilância;

IA e trabalho;

design manipulativo;

obsolescência;

precarização;

consequências das Big Techs.

Exemplos:

A inteligência artificial está tornando a internet pior?

Quem realmente ganha quando um aplicativo é gratuito?

Por que todos os sites estão começando a parecer iguais?

16. Posicionamento editorial

A Baixa Resolução não deve ser apenas um agregador de notícias.

A proposta é:

Olhar para a tecnologia de perto o suficiente para enxergar suas contradições.

A publicação deve tratar tecnologia como:

indústria;

ferramenta;

produto;

cultura;

infraestrutura;

comportamento;

política;

economia;

design;

transformação social.

17. Linguagem

A escrita deve ser:

inteligente;

direta;

crítica quando necessário;

acessível;

contemporânea;

informativa;

ocasionalmente provocativa.

Evitar:

linguagem corporativa;

clickbait barato;

excesso de jargão;

entusiasmo artificial com toda nova tecnologia;

"revolucionário" para qualquer lançamento;

linguagem típica de release de empresa.

18. Relação com a origemdev

A Baixa Resolução deve funcionar como uma publicação independente associada à origemdev.

A marca principal aparece de maneira discreta:

BAIXA RESOLUÇÃO

por origemdev

A origemdev não deve dominar visualmente o editorial.

A publicação precisa ter personalidade própria.

19. Assinatura

A assinatura conceitual principal é:

Alta tecnologia. Baixa resolução.

Ela resume a contradição central da identidade:

um olhar analógico, crítico e editorial sobre um mundo cada vez mais digital.

A Baixa Resolução deve parecer uma publicação que poderia existir fisicamente.

Uma revista encontrada em uma banca, mas falando sobre:

inteligência artificial;

internet;

robôs;

algoritmos;

cultura digital;

tecnologia;

futuro.
````
